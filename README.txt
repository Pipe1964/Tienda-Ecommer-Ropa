ATELIER NORTE — DEMOSTRACIÓN DE TIENDA DE ROPA
================================================

ARCHIVOS
- index.html: estructura, textos y catálogo de demostración.
- styles.css: diseño visual y adaptación a móviles.
- script.js: menú móvil, filtros de productos y consultas por WhatsApp.

ABRIR EN WINDOWS
1. Descarga el ZIP y selecciona clic derecho > Extraer todo.
2. Abre la carpeta extraída.
3. Haz doble clic en index.html para abrir la página en tu navegador.
4. Para modificar el código, abre la carpeta en Visual Studio Code.

PERSONALIZAR WHATSAPP
1. Abre script.js.
2. Busca whatsapp: ""
3. Escribe el número real de la tienda con indicativo internacional, solo números.
   Ejemplo de formato colombiano: 573001234567
4. Guarda el archivo y vuelve a cargar la página.

PERSONALIZAR CATÁLOGO
- En index.html, cambia nombre de marca, productos, precios, categorías, descripciones,
  dirección y textos por la información real del cliente.
- Reemplaza las imágenes ilustrativas por fotos del negocio o imágenes cuyo uso comercial
  esté permitido.
- Revisa que las tallas, precios, inventario, envíos y condiciones sean reales antes de publicar.

PUBLICAR GRATIS CON GITHUB PAGES
1. Crea una cuenta en https://github.com/
2. Crea un repositorio público, por ejemplo atelier-norte.
3. Sube index.html, styles.css y script.js a la raíz del repositorio.
4. Entra a Settings > Pages.
5. En Build and deployment, selecciona Deploy from a branch.
6. Elige la rama main y la carpeta /(root), y guarda.
7. Espera a que GitHub Pages publique el sitio. El enlace aparecerá en Settings > Pages.

LIMITACIONES DE ESTA DEMO
- No es una tienda con carrito, inventario, pagos en línea ni gestión de pedidos.
- Las consultas se envían por WhatsApp; el comprador y la tienda deben confirmar disponibilidad.
- Google Fonts e imágenes remotas requieren internet.
- Los nombres, precios y textos son ficticios.
- No incluyas contraseñas ni datos privados en un repositorio público.
